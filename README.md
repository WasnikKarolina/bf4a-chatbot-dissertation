# Bright Futures 4 All Website Chatbot

A retrieval-based chatbot for the Bright Futures 4 All charity website. 
It supports:
- Website navigation assistance
- FAQ answering using website content
- Donation and Gift Aid guidance
- Mini quizzes to promote engagement
- Resource recommendations and success stories
- Extractive summaries of website pages


## Repo structure
- backend/      Chatbot engine + API
- wix-frontend/ Wix Velo code snippets and integration notes
- data/         Scraped pages, cleaned text, chunks, FAQs
- tests/        Unit, integration, and evaluation tests
